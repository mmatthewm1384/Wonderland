# Wonderland Academy Engine

Academy Engine 1.0 provides deterministic structural verification and
certification around Wonderland Academy content and registries.

## Structural commands

```text
wl academy doctor
wl academy verify
wl academy certify
wl academy status
Operational commands
wl academy lesson
wl academy chapter
wl academy list
wl academy show
wl academy search
wl academy progress
wl academy quality

Operational commands delegate to the preserved Academy implementation.
Verification and certification do not mutate learner progress or Academy
content.
