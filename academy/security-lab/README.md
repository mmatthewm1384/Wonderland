# Wonderland Security Lab

The Security Lab exists for defensive learning and authorized testing.

Allowed targets:

- systems owned by the operator
- local lab machines
- intentionally vulnerable training targets
- disposable containers or VMs created for practice

Not allowed:

- third-party systems without permission
- public targets without authorization
- credential theft
- evasion against real services
- destructive testing outside isolated labs

Principle:

Understand by building. Learn by testing. Improve by defending.
