# Module 1 — Foundations

## Purpose

Build the mental models required to understand how computers work, how operating systems organize resources, and how Wonderland uses those foundations.

## Completion Criteria

- Complete Days 001–030.
- Complete each lab.
- Complete each quiz.
- Maintain the learning journal.
- Pass `wl academy module1`.
