# Wonderland Academy

Wonderland Academy is the understanding engine.

It teaches:

- systems thinking
- operating systems
- networking
- containers
- programming
- infrastructure
- privacy
- encryption
- defensive security
- Wonderland internals

Every lesson should answer:

1. What is it?
2. Why does it exist?
3. How does it work?
4. How can it fail?
5. How do we protect it?
6. How do we verify it?
7. How do we explain it?
