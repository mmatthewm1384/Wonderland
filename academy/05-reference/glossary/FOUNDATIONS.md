# Foundations Glossary

Core Terms
Bit: the smallest binary unit of information.
Byte: commonly 8 bits.
State: the current condition or value of a system.
Process: a running program.
Filesystem: the structure used to organize files and metadata.
Permission: a rule controlling access or execution.
Environment variable: a named value exposed to processes.
Virtual machine: an emulated or virtualized computer environment.
Container: an isolated process environment using OS-level primitives.
Observability: the ability to understand system behavior from outputs.
