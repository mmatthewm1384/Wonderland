# Wonderland Academy Canon 1.0

## Purpose

The Canon defines the permanent body of engineering knowledge that Wonderland Academy is committed to teaching.

The curriculum may evolve. Tools may change. Wonderland itself will grow.

The Canon describes the enduring knowledge, skills, and engineering habits that every Wonderland Academy graduate should develop.

---

## Canon I — Foundations of Computing

**Theme:** Understand information.

### Topics

- Binary
- Hexadecimal
- Data representation
- CPU architecture
- Memory
- Storage
- Filesystems
- Operating-system fundamentals

### Outcome

A graduate understands how computers actually work, from bits and bytes through programs, processes, files, and system behavior.

Wonderland Academy teaches technical skills through durable engineering habits.

- Curiosity
- Humility
- Precision
- Patience
- Discipline
- Integrity
- Generosity
- Stewardship

---

# The Three Questions

Every lesson should answer:

1. **How does it work?**
2. **Why was it designed this way?**
3. **How does this improve Wonderland?**

If a lesson cannot answer all three, it is incomplete.

Graduation Standard

A Wonderland Academy graduate should be able to:

Explain systems from first principles.
Build production-quality software.
Operate and recover infrastructure.
Secure systems thoughtfully.
Design maintainable architectures.
Communicate technical ideas clearly.
Mentor others effectively.
