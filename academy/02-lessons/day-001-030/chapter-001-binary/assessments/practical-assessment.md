# Practical Assessment — Chapter 001

## Objective

Demonstrate that binary concepts can be observed inside Wonderland.

## Tasks

1. Inspect a text file with `xxd`.
2. Inspect a Wonderland executable with `file`.
3. Inspect the current Git commit with `git cat-file -p HEAD`.
4. Observe command exit codes with `true`, `false`, and `echo $?`.
5. Explain one place where binary is hidden beneath a higher-level abstraction.

## Passing Criteria

- All commands executed successfully.
- Observations recorded in the journal.
- Explanation distinguishes representation from interpretation.
