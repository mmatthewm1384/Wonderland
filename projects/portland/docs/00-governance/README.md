# Governance and repository control

This directory contains the project's governing documents, policies, and
repository operating rules. The Notion Project Charter and Foundational Master
Specification remain the current project-level references; this repository
scaffold does not silently duplicate or supersede them.

## Required controls

- Keep project authority distinct from public/municipal authority.
- Preserve the Draft / Proposed state until explicit acceptance.
- Use KNOWN, DERIVED, PROPOSED, SPECULATIVE, and UNKNOWN consistently.
- Record decisions in ADRs; do not bury architectural decisions in chat or code.
- Use GDIR for global document identity. Local paths and filenames are locators.
- Ask before introducing new global registries, authority structures, or schemas.
