# Domain interface contract — template

Each domain specification must declare:

1. Purpose, scope, exclusions, geography, and time boundary.
2. Authority and source hierarchy.
3. Inputs, outputs, schemas, units, and coordinate reference systems.
4. Upstream dependencies and downstream consumers.
5. Ownership, custody, maintenance, and update expectations.
6. Failure modes and uncertainty propagation.
7. Validation methods and acceptance criteria.
8. Security, privacy, licensing, and distribution constraints.
9. Change control and supersession behavior.

No domain may silently redefine shared terms, boundaries, authoritative sources,
or system responsibilities.
