**Workstream status:** Proposed

## Mandate

Water, wastewater, energy, communications, waste, public facilities.

## Required outputs

- Domain scope and boundary specification.
- Source and dataset inventory.
- Evidence-backed existing-condition baseline.
- Methods, assumptions, limitations, and uncertainty record.
- Cross-domain interfaces and dependencies.
- Validation and acceptance report.
- Proposed interventions only after baseline acceptance.

## Directory use

- `spec/` — domain requirements and interface contracts.
- `research/` — research briefs and baseline studies.
- `data/` — domain-specific dataset manifests (not bulk data payloads).
- `models/` — analytical methods and model contracts.
- `outputs/` — approved derivative outputs; generated files are normally ignored.
- `evidence/` — domain validation and review evidence.
