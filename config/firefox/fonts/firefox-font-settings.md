# Firefox Font Settings — Wonderland

Open Firefox:

Settings → General → Language and Appearance → Fonts → Advanced

Set:

- Proportional: Sans Serif
- Size: 16
- Serif: Inter
- Sans-serif: Inter
- Monospace: JetBrainsMonoNL Nerd Font Mono
- Monospace Size: 13
- Minimum Font Size: None
- Allow pages to choose their own fonts: enabled
