Summary

Wonderland Operator is now a first-class Wonderland subsystem.

It provides a local-first operational control plane for observing, presenting, and orchestrating Wonderland platform state through a tmux frontend, capability registry, health model, workspace system, event log, notification log, and stable JSON status contract.
