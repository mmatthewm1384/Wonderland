# Wonderland Integrity Attestation Protocol

This protocol records local operator-approved integrity events.

It does not enforce honesty, personality, identity, behavior, or thought patterns.

## Allowed

- File integrity checkpoints
- Config state attestations
- Recovery events
- Runtime checkpoints
- Operator-approved audit records

## Forbidden

- Personality enforcement
- Behavioral profiling
- Mandatory oath compliance
- Public personal data export
- Human honesty scoring
- Fabric/Hedera dependency by default
