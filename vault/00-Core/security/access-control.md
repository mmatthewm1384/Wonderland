# Access Control
<!-- id: access-control-v4 -->

## Purpose

Define access expectations for Wonderland systems.

## Principle

Default access is denied unless explicitly granted.

## Local Access

Local operator access is privileged but must remain auditable.

## Service Access

Services should use the minimum permissions required to operate.

## External Access

External access must be documented, intentional, and revocable.

## Status

state: active
version: 4

## Governance Principle

This component may be destroyed and rebuilt without loss of authority.

Authority resides in:

- documented intent
- service definitions
- recovery procedures
- version-controlled governance records

Runtime state is disposable.
Authority is not.
