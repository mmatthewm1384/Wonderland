# Architectural Doctrine
<!-- id: architectural-doctrine-v4 -->

## Doctrine

Wonderland systems must be persistent, recoverable, auditable, secure, automated, versioned, and modular.

## Persistent

Systems must survive shell sessions, reboots, service restarts, and operator absence.

## Recoverable

Every promoted system must define how to restore it from a clean state.

## Auditable

Important changes must leave readable evidence in files, logs, commits, or manifests.

## Secure

Secrets, credentials, permissions, and external access must be explicitly controlled.

## Automated

Repeatable work should be encoded as scripts, commands, manifests, or runbooks.

## Versioned

Documents, scripts, configuration, and infrastructure definitions must be version controlled.

## Modular

Systems should be separable, replaceable, and independently verifiable.
