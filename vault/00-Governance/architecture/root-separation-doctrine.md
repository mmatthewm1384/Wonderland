# Root Separation Doctrine

## Authority

`~/Wonderland` is the authority root.

It contains durable knowledge, governance, canon, registries, intents, documentation, policies, runbooks, templates, and recovery metadata.

## Build

`~/Workshop` contains active source code, apps, services, experiments, prototypes, and repositories.

## Runtime

`~/Runtime` contains execution state: logs, cache, tmp data, ports, container runtime metadata, and machine-local generated state.

## Archive

`~/Archive` contains retired, deprecated, imported, or cold local materials.

## Media

`~/Media` contains creative and non-authority assets.

## Rule

Wonderland may describe, govern, restore, and verify the system.

Wonderland should not contain disposable build state, runtime state, dependency folders, generated artifacts, or large media unless they are explicitly authority artifacts.
