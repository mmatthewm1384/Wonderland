# WEL-001 — Wonderland Escalation Language

Status: Authority  
Version: 1.0  
Applies to: Wonderland OS, Control Center, Models, Chaos, Scheduler, Dashboard, Observatory, Clipboard

## Principle

Progression is not danger. Authority is protection.

Escalation communicates operational phase, not system health.

## Phase System

| Phase | Name | Color | Hex | Motion | Geometry |
|---:|---|---|---|---|---|
| 0 | Foundation | Cyan | #00E5FF | Static | Core |
| 1 | Awareness | Azure | #2BA7FF | Slow breathe | Facet |
| 2 | Attention | Indigo | #4A6BFF | Gentle rotation | Cut |
| 3 | Transition | Purple | #7000FF | Continuous rotation | Star |
| 4 | Pressure | Magenta | #C000FF | Rotation + pulse | Resonance |
| 5 | Authority | White | #EAF7FF | Locked / frozen | Seal |

## Health System

Health is independent from escalation.

| State | Hex |
|---|---|
| Healthy | #22D07D |
| Warning | #FFB020 |
| Offline / Error | #FF4D4F |

## Accessibility

Color, motion, and geometry must always be paired with text labels.
Reduced-motion mode must disable continuous animation.
