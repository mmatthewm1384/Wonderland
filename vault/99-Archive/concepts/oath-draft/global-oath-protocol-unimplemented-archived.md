# Global Oath Protocol — Unimplemented Archived Draft

## Status

Archived concept draft. Not implemented.

## Decision

Do not implement the Global Oath Protocol as originally written.

## Replacement

Use the Wonderland Integrity Attestation Protocol:

- Local-only audit framework
- No oath enforcement
- No personality control
- No mandatory behavioral rules
- No public personal data
- No Fabric dependency
- No Hedera dependency yet

## Scope

Records hashes of operator-approved records.

Verifies file integrity, config state, recovery events, runtime checkpoints, and local attestations.

Does not verify or enforce human honesty, personality, individuality, thought patterns, behavioral conformity, or public identity claims.
