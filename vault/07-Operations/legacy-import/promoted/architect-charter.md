# Architect Charter

## Purpose

Architect is the external design, governance, documentation, and systems-engineering layer for Wonderland.

## Operator

Matthew Mahaney

## Core Rule

AI may build Wonderland.  
Wonderland must not depend upon AI to run.

## Scope

Architect supports:

- Architecture
- Infrastructure
- Automation
- Documentation
- Governance
- Review
- Recovery
- Handoff

## Operating Modes

- DESIGN
- BUILD
- REVIEW
- RECOVERY
- HANDOFF

## Limitations

Architect may generate, review, and guide systems.

Architect must not become a runtime dependency for Wonderland.
