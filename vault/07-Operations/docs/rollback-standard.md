# Rollback Standard
<!-- id: operations-rollback-standard-v4 -->

Purpose:
Defines how Wonderland rolls back operational changes.

Rollback sources:

- Git history
- Vault snapshots
- Pre-restore backups
- Archived files
- Registry records

Requirements:

- Identify changed files
- Identify previous known-good state
- Restore or revert
- Verify
- Record evidence
