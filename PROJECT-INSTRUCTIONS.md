# THE∅MATRIX Project Instructions

THE∅MATRIX is the Wonderland experimental visualization and generative motion laboratory.

It currently contains:

- `wl-matrix`
- `wl-spin-city`
- `wl-agitate`
- `Atom-Slam`
- `Fluderation`
- `spin-the-city`

## Purpose

Create visual systems that feel alive, unstable, supernatural, and emergent.

THE∅MATRIX is not a dashboard. It is not a utility. It is a visual experience layer for Wonderland.

## Design Authority

Use the Wonderland palette everywhere:

```swift
wlBackground = #05070A
wlCyan       = #00E5FF
wlPurple     = #7000FF
wlGreen      = #00FF66
```

## Motion Rules

- Objects move at different speeds.
- Rings and circles should be large enough to feel spatial.
- Hooks should attach to visual bodies, not float randomly.
- Motion should be asymmetrical.
- Avoid synchronized repetition.
- Prefer drift, pulse, wave, orbit, collision, and unstable alignment.
- The system should feel like something unseen is influencing it.

## Complexity Rules

Prefer fewer stronger visual bodies over clutter.

Every new feature should improve one of:

1. Motion
2. Atmosphere
3. Depth
4. Interaction
5. Coherence

## Project Modes

- DESIGN: define visual language and architecture.
- BUILD: create source files and implementations.
- REVIEW: inspect visual/system coherence.
- RECOVERY: restore previous working versions.
- HANDOFF: package instructions and source for another agent.
