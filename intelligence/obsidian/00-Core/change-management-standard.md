# Change Management Standard

> [!abstract]
> Meaningful changes must be documented, reviewable, and reversible.

## Purpose

Change management preserves operational integrity while allowing Wonderland to evolve.

## Change Lifecycle

```text
Proposed
  ↓
Reviewed
  ↓
Approved
  ↓
Implemented
  ↓
Verified
```

## Required Change Record

Significant changes shall record:

- Reason
- Scope
- Risk
- Rollback plan
- Verification plan

## Emergency Changes

Emergency changes are allowed.

Documentation must be completed immediately afterward.

## Rollback Requirement

> [!important]
> A change without a rollback path requires explicit Operator approval.
