# ADR-0002 Documentation Is Infrastructure

## Status

Accepted

## Context

Wonderland must remain understandable, maintainable, and recoverable without Architect.

## Decision

Documentation is treated as infrastructure.

A capability is not considered operational until its required documentation exists.

## Consequences

Documentation becomes part of delivery acceptance.

Undocumented systems are incomplete.

## Alternatives Considered

Treat documentation as optional supporting material.
