# ADR-0017 Intent Files For Auditable Operations

## Status

Accepted

## Context

Wonderland needs durable records of requested operational outcomes.

## Decision

Adopt `.intent.json` files for structured operation intent where useful.

## Consequences

Intent can be reviewed, versioned, validated, and preserved before execution.

## Alternatives Considered

Use only shell command history or freeform notes.
