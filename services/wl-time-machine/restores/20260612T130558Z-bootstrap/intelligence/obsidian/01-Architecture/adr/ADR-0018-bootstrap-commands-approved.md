# ADR-0018 Bootstrap Commands Approved

## Status

Accepted

## Context

Wonderland requires minimal bootstrap commands before platform services are built.

## Decision

Approve initial bootstrap commands:

- `wl-init`
- `wl-status`
- `wl-verify`

## Consequences

The local workspace can be initialized and verified through standard commands.

## Alternatives Considered

Manual-only bootstrap.
