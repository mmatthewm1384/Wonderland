# WL-GOV-003 — Service Promotion Standard

## Status

Active

## Purpose

No service is promoted into Wonderland runtime authority until it has passed structure, recovery, and governance checks.

## Required Promotion Gates

A promoted service must include:

1. Service directory
2. Compose or runtime definition
3. wl-* command wrapper
4. Doctor check
5. Logs command
6. Repair command
7. Recovery documentation
8. Governance footer

## Principle

Runtime state is disposable.
Authority is not.
