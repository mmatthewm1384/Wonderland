# ADR-0013 Service Definition Standard

## Status

Accepted

## Context

Wonderland services require consistent structure, documentation, verification, and recovery expectations.

## Decision

Adopt the Service Definition Standard as the minimum required model for Wonderland-v4 services.

## Consequences

Services are not considered operational until they meet the standard.

Service templates become the preferred starting point for new capabilities.

## Alternatives Considered

Allow each service to define its own structure.
