# Naming Standard

## Commands
Format: `wl-<action>`

## Services
Format: `wl-<service>`

## Containers
Format: `wl-<service>`

## Networks
Format: `wonderland-<scope>`

## Volumes
Format: `wl-<service>-data`

## Repositories
Format: `wonderland-<component>`

## Documentation
Format: `lowercase-kebab-case.md`

## ADRs
Format: `ADR-XXXX-title.md`
