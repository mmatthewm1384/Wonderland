# Chronosphere v2 Design

## Model

Chronosphere v2 is a Reality Reconstruction Engine.

A portal is defined by:

```text
time + place + identity + reality
```

## Portal files

Each portal includes:

- `portal.json`
- `identity.json`
- `environment.json`
- `timeline.json`
- `reality.json`
- `actions.json`
- Obsidian portal note

## Visit sequence

Enter → Reconstruct → Embody → Act → Record → Return
