# Wonderland-v4 GA+ Operator Manual

## Startup

```bash
source ~/.zshrc
wl status
wl start
wl doctor
```

## Shutdown

```bash
wl stop
```

## DNS

```bash
wl dns test
```

## Snapshot

```bash
wl snapshot
```

## Mirror to T7

```bash
wl mirror once
```

## Security

```bash
wl security doctor
```

## Knowledge

Open:

```bash
$WL_HOME/04-knowledge/vault
```

as an Obsidian vault.

## Recovery

Use:

```bash
$WL_HOME/08-operations/recovery
```
