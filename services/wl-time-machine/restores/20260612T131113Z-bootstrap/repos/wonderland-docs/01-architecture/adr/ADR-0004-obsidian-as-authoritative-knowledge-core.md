# ADR-0004 Obsidian As Authoritative Knowledge Core

## Status

Accepted

## Context

Wonderland requires a durable, human-readable knowledge repository.

## Decision

Obsidian is the authoritative knowledge core for Wonderland-v4 documentation and governance records.

## Consequences

Canonical governance, architecture, standards, registries, and operational documentation should exist in the Obsidian vault.

Knowledge remains portable as Markdown.

## Alternatives Considered

Use only repository READMEs, wiki systems, or external SaaS documentation platforms.
