# Operations Playbook

## Daily

- Review health
- Review backups
- Review storage
- Review logs

## Weekly

- Verify recovery procedures
- Verify documentation accuracy
- Review infrastructure changes

## Monthly

- Backup restoration testing
- Security review
- Capacity review

## Incident Response

1. Identify
2. Contain
3. Recover
4. Verify
5. Document

## Recovery

All incidents must produce recovery documentation.
