# WL-GOV-002 — Recovery Documentation Standard

## Status

Active

## Purpose

Every Wonderland service, command, and subsystem must include recoverable operating documentation.

## Required Sections

Each recovery-bearing document must include:

1. Purpose
2. Authority
3. Runtime State
4. Backup Location
5. Recovery Procedure
6. Verification Procedure
7. Rollback Procedure

## Principle

Runtime state is disposable.
Authority is not.
