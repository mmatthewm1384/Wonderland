# Exception Standard
<!-- id: exception-standard-v4 -->

Purpose:
Defines how exceptions are recorded.

An exception must include:

- Reason
- Scope
- Expiration or review date
- Risk
- Rollback or mitigation

state: active
version: 4

## Governance Principle

This component may be destroyed and rebuilt without loss of authority.

Authority resides in:

- documented intent
- service definitions
- recovery procedures
- version-controlled governance records

Runtime state is disposable.
Authority is not.
