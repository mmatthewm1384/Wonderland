Purpose:
Defines how Wonderland records operational evidence.

Audit command:
    wl audit

Audit reports should include:

- Verification result
- Vault inventory
- Lifecycle state
- Runtime state
- Timestamp

## Governance Principle

This component may be destroyed and rebuilt without loss of authority.

Authority resides in:

- documented intent
- service definitions
- recovery procedures
- version-controlled governance records

Runtime state is disposable.
Authority is not.
