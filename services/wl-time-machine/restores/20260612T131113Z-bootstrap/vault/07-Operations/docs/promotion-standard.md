# Promotion Standard
<!-- id: promotion-standard-v4 -->

Purpose:
Defines promotion authority and evidence requirements.

Promotion requires:

- Operator approval
- Verification result
- Recovery path
- Rollback path
- Registry update
- Audit evidence

state: active
version: 4

## Governance Principle

This component may be destroyed and rebuilt without loss of authority.

Authority resides in:

- documented intent
- service definitions
- recovery procedures
- version-controlled governance records

Runtime state is disposable.
Authority is not.
