# System Context

> [!abstract]
> This document defines the top-level system context for Wonderland-v4.

## Primary Actors

### Operator

The final authority for Wonderland.

### Architect

External design, governance, documentation, and systems-engineering intelligence layer.

Architect may assist but must not become a runtime dependency.

## Core Systems

### Governance

Charters, constitution, standards, decision records, and operating policy.

### Knowledge Core

Obsidian vault containing durable operational knowledge.

### Platform

Infrastructure, runtime, networking, storage, and execution environment.

### Services

Applications, APIs, containers, workflows, and workloads.

### External Systems

Cloud services, registries, identity systems, source repositories, vendor services, and public internet dependencies.

## Context Rule

> [!important]
> Wonderland must remain operable without Architect.
