# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Wonderland (including Crystal, Spark isolation boundaries, or Crystal Mesh governance), please report it responsibly.

- **Private Disclosure**: Do not open a public GitHub issue for security vulnerabilities.
- **Reporting Channel**: Open a security advisory directly on GitHub or contact the maintainer at the repository owner's primary address.
- **Response Timeline**: You will receive an acknowledgment within 48 hours, followed by a coordinated disclosure and patch verification plan.
